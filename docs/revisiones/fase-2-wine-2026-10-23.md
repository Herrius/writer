# Fase 2 — Prueba parcial del CLI Windows bajo Wine

- **Fecha:** 2026-10-23
- **Commit:** `766ba91` (código de producto; el binario se recompiló desde HEAD)
- **Entorno:** Docker `rust:1.89-bookworm` con `x86_64-pc-windows-gnu` y
  `mingw-w64`; ejecución con `scottyhardy/docker-wine` (Wine 11.0) en Linux
  x86_64.
- **Alcance:** CLI y núcleo. **No** se probó la app Tauri ni WebView2.

## 1. Binario

```text
cargo build --release --locked --target x86_64-pc-windows-gnu -p writer-cli
writer.exe  7,9 MB
```

## 2. Smoke test ejecutado

Todo dentro del prefijo Wine, con rutas Windows (`C:\wine-fase2-full`):

```text
writer.exe init --titulo "Novela Wine" --autor "Autora" C:\wine-fase2-full
writer.exe create escena --titulo "Escena Wine" C:\wine-fase2-full
writer.exe list C:\wine-fase2-full
writer.exe write <ID> --texto "Contenido escrito en Wine." C:\wine-fase2-full
writer.exe read <ID> C:\wine-fase2-full
writer.exe buscar "Wine" C:\wine-fase2-full
writer.exe export md C:\wine-fase2-export.md C:\wine-fase2-full
writer.exe export docx C:\wine-docx.docx C:\wine-docx
writer.exe verify C:\wine-fase2-full
```

Resultado: **OK**. `verify` devuelve `resultado: OK`; la búsqueda encuentra la
escena; la lectura devuelve el cuerpo escrito; export Markdown y DOCX terminan
sin error.

## 3. Pruebas de núcleo bajo Wine

El binario de tests del núcleo ejecutado con Wine pasa **67/67** pruebas
unitarias. Las pruebas de integración y CLI no son concluyentes en este montaje:
sus rutas de fixtures y del binario se compilan con rutas Unix
(`/work/...`) y Wine no las resuelve; los fallos son del arnés de
cross-compilación, no del producto. Por eso el smoke test manual es la evidencia
válida.

## 4. Lo que Wine no valida

- **Tauri GUI:** WebView2 no está disponible de forma fiable en Wine; la ventana
  y el editor no se probaron.
- **Instalador MSI/NSIS**, WebView2, diálogos nativos, asociaciones de archivo,
  rutas largas y cierre de ventana en Windows real.
- **Word/LibreOffice** abriendo el DOCX generado.
- **Windows nativo**: Wine no sustituye una máquina Windows ni un runner CI.

## 5. Decisión

Wine sirve como **prueba parcial del CLI/núcleo Windows** y confirma que las
rutas, locks, SQLite/FTS5, escritura atómica, exportación y verificación
funcionan en un entorno Windows-like. **No autoriza declarar Windows soportado**:
sigue pendiente el build/instalación/pruebas de la app Tauri en Windows real.
