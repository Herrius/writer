# Iteración 27 — Fase 3.3: formato, preferencias y paleta

- **Fecha:** 2026-10-24
- **Estado:** implementado y probado en Linux x86_64.
- **Contrato:** [`../formato-v1.md`](../formato-v1.md).

## 1. Qué se implementó

- Preferencias locales de tema (claro, sepia, oscuro), tipografía, tamaño,
  interlineado y espacio entre párrafos.
- Variables CSS aplicadas al editor y a la vista de escritura.
- Modal de preferencias accesible, con trampa de foco, `Escape` y restauración
  del foco.
- Modo enfoque con `Alt+Z`, persistido en las preferencias.
- Quick Open con `Ctrl+P` para abrir documentos por título o ruta.
- Paleta de comandos con `Ctrl+Shift+P` para guardar, buscar, historial,
  cambios, preferencias, temas y exportaciones.
- Atajo `Ctrl+Shift+H` para el historial.
- Corrector nativo del WebView activable/desactivable.
- El botón de configuración del árbol y un botón nuevo de la barra superior
  abren las preferencias.

## 4. Límites

- Preferencias por perfil de WebView, no por proyecto.
- Sin temas personalizados ni importación/exportación de ajustes.
- El corrector es el nativo de la plataforma; no se empaqueta diccionario,
  tesauro ni gramática.
- La paleta lista comandos fijos; no es un sistema de plugins.
